# 試點批次01：關鍵字決標（2023-01-01 ～ 2026-12-31）

## 本批實際產出（2026-11-17）
- `pcc_batch01.csv`、`summary.txt`：由 `pcc_batch01_api.py` 產生，**資料來源為第三方 API pcc-api.openfun.app**（g0v／openfun，資料收集自政府電子採購網）。官方網站拒絕雲端 IP，經使用者同意改用此 API。
  授權依採購網著作權聲明（合理使用、需註明出處），**不是**政府資料開放授權條款。CSV 的「原始公告網址」仍指向採購網官方公告頁，可逐筆回查。
- 去個資後的原始決標公告存放在 repo 根目錄 `raw/`，檔名格式為 `<公告日期>_<公告檔名>.json`。
- 若要改用官方來源重跑，請在台灣網路環境執行下方的 `pcc_batch01.py`。

## 資料來源（只用官方來源）
- 行政院公共工程委員會「政府電子採購網」開放資料下載頁：<https://web.pcc.gov.tw/tps/tp/OpenData/showList>
- 商業利用資料集入口（採購網公告）：<https://web.pcc.gov.tw/tpsreport/transfer/dataTransfer.do?method=getOkfnOpenDataXml>
- 政府資料開放平臺上工程會的資料集（例如 6155、165150、172023）都標示「政府資料開放授權條款-第1版」，下載點也都在 web.pcc.gov.tw。
- 注意：data.gov.tw 的 16371「決標公告」是經濟部中小及新創企業署的委辦計畫資料，**不是**採購網資料，不要用。
- 不使用 g0v／openfun 等第三方鏡像。

> 2026-11-17 在雲端環境（海外 IP）執行時，web.pcc.gov.tw 的所有端點都回應 “Web Page Blocked”（Attack ID 20000021），
> 所以官方檔案的實際格式、檔名規則和授權頁面都還沒確認。請在台灣網路環境執行，第一次執行後請核對 raw/ 的檔案格式。

## 執行
```bash
cd "05_原始資料/PCC_政府電子採購網/試點批次01_關鍵字決標_2023-2026"
python3 pcc_batch01.py
```
- 會從 showList 頁面擷取檔名含 award／決標、日期在範圍內的檔案（排除 GPA），以原始檔名存到 `./raw/`。
- 如果自動下載失敗：手動從官網下載後放進 `./raw/`，再執行 `python3 pcc_batch01.py --skip-download`。
- 支援 XML、JSON、CSV、ZIP 和 UTF-8／Big5 編碼；欄位名稱用候選清單比對（見腳本裡的 `F`）。如果官方欄位名稱不同，請補進清單。

## 篩選規則
1. 決標日期 2023-01-01～2026-12-31（民國年會自動轉換）
2. 標的分類含「勞務」
3. 總決標金額 ≥ 400,000
4. 標案名稱命中關鍵字（比對前先做全形轉半形、去空白、英文轉大寫，所以「ISO14064」也算命中）

| 類別編號 | 類別 | 關鍵字 |
|---|---|---|
| 01 | 永續旅遊／觀光 | 永續旅遊、永續觀光、GSTC、永續標章、旅行業輔導 |
| 02 | 溫室氣體與碳管理 | 溫室氣體盤查、碳足跡、ISO 14064、碳盤查 |
| 03 | 低碳社區與氣候調適 | 低碳永續家園、淨零社區、社區減碳、氣候變遷調適 |
| 04 | 原住民族產業與人才 | 原住民族產業、產業聚落、原住民族＋人才培訓、原住民族＋永續發展 |
| 05 | 成效與社會影響力評估 | 成效評估、社會影響力、SROI、影響力評估、社會投資報酬 |

類別編號是自訂的。一案命中多個類別時，用「；」串接。

## 輸出
- `out/pcc_batch01.csv`（UTF-8 BOM）：每家得標廠商一列。「決標金額」優先填該廠商的決標金額，沒有時填總決標金額。
- `out/summary.txt`：各類別、各年度的列數（標案數），以及各篩選條件排除的筆數（依序套用，以公告為單位）。

## 去識別
- 不輸出聯絡人等自然人欄位。
- 得標廠商判定為個人時，名稱改為「個人」，統編留空。判定條件：廠商代碼不是 8 碼統編（例如遮罩的身分證號）、名稱是 2–4 個中文字且沒有組織字樣，或沒有代碼也沒有組織字樣。
- 這是規則式判定，輸出後請人工抽查。
