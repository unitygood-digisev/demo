## 第 1 輪（2026-10-17）：從零建置《永續情報雷達》

### 使用者
（全文見「原始需求提示詞」。）要求做出單一 HTML＋兩支 Vercel 函式的《永續情報雷達》，離線規則引擎可用、有 AI 時提供深度解讀等功能，所有數字附出處與日期，並依測試清單驗證、依部署步驟部署。

### Claude 的工作過程
1. **先研究再寫程式**：同時派出 5 個研究代理，分別查證 N1～N6 種子情報、法規與國際新聞、同業與市場數據新聞、碳價基準與匯率、三組時間序列。另親自下載環境部碳費費率審議會會議紀錄 PDF（113 年第 5、6 次，115 年第 1 次）與公視新聞比對關鍵數字。
2. **後端**：照抄使用者提供的 `api/claude.js`、`api/news.js`、`package.json`、`vercel.json`，並確認 Claude API 用法（模型 `claude-opus-5-5`、effort、伺服器端拒答備援）正確。
3. **前端**：單一 `index.html`，手寫 SVG 圖表、六個分頁、三種 AI 環境（Artifact／網站／離線）。
4. **測試**：用 Playwright 逐項跑測試清單；測試中發現「六個分頁同時顯示」的錯誤（CSS 覆蓋了 hidden 屬性）並修正；檢查 33 個來源網址全部 HTTP 200。
5. **文件**：小組規劃會議紀錄、README、查證報告。
6. **發布**：Artifact 發布 Claude 版；推送程式碼。Vercel 因容器內沒有使用者的登入而未部署。

**連結**

**測試結果**
- 離線模式：本機開檔，6 個分頁主控台都沒有錯誤；頁首顯示「離線模式（規則引擎）」，AI 按鈕全部隱藏。
- 規則引擎：範例標題「環境部預告碳費…明年起上路」判定為法規政策、碳費與自主減量、重要度高。
- 碳費：30,000 噸一般費率為 NT$9,000,000；滑桿 200、1,000、4,000 時統計卡與解讀都會改變。
- 問情報官離線：「CBAM 憑證」列出 N5、N6（另有 N10、N14）。
- 週報：2026-10-17 為 ISO 第 42 週，「複製週報」可以複製。
- 版面：375px 寬度沒有水平捲動，深淺色都可讀。
- 新聞函式：抓到 25 則真實新聞。Claude 函式：假金鑰 GET 回 `{ok:true}`，空字串與 16,001 字都回 400。
- 來源：33 個連結都回 200，關鍵數字已在原文比對。
- 另用本機伺服器模擬網站模式（假的 Claude 回覆）測過深度解讀、貼上抽取、主管摘要、附引用問答與 429 訊息，都正常；這不是真的 Claude API 測試。
- 測試中發現並修好一個錯誤：在 Artifact 以外，六個分頁會同時顯示。

**查證重點**（完整見「查證報告」）
- N4：找到金管會與環境部 2026-09-23 共同新聞稿原文，保留；強制適用由 1,970 家調整為約 560 家。
- N6：改寫成「約九成進口商豁免，仍涵蓋逾 99% 的內含排放」，原句「不到 1%」容易誤讀。
- N2：標明是審議會建議（2030 年目標每公噸 1,200～1,800 元），環境部尚未公告第二期費率。
- 較舊的價格已在頁面標註：韓國 K-ETS 是 4 月拍賣價；碳交所國際碳權是 2023 年 12 月開市的上架訂價區間。
- 未納入：查驗證機構新服務的新聞找不到可確認的，改用 TRE100；EU ETS 2025 年均價與日本 289 日圓碳稅無法確認。
- 缺值：2025 年國家排放量尚未公布，圖上標「未取得」。

### Claude 的回覆（最終答覆）
我已依照「優樂地管理層系統」的新聞週報優化網站，Claude 版已更新：https://claude.ai/artifact/A6hHCHB45D4zZiMMEyMpAF

**你的 Vercel 網址還是舊版。** 專案在你的帳號下，我沒有登入無法更新。請在 `sustainability-radar/web/` 執行 `npx vercel login`、`npx vercel link --yes --project <你的專案名稱>`、`npx vercel deploy --prod --yes`，網址不變。

**改了什麼**
- 分組一致：自家品牌、法規與準則、政府採購與政策、同業動態、客戶動態、其他。
- 服務線：影響面向改成優樂地的 12 條服務線（例如生物多樣性與 TNFD、影響力投資與 SROI、永續觀光與醫療）。
- 關鍵字規則：沿用副執行長 10/15 提供的 23 組關鍵字與權重（雲端版，不含客戶與人名）；每則顯示「相關度 N 分（命中：…）」；「ESG、永續、淨零」和主管機關名稱要同時命中其他關鍵字才算。
- 即時新聞換來源：Google News 使用條款禁止程式讀取，改用管理層系統的 36 個公開 RSS 來源。實測 35 個成功、近 7 天 406 則、篩出 7 則相關；失敗的列在「來源異常」（GSTC），沒命中的放進「附錄：低相關與未列入」。
- 週報格式：第一句先下結論；每則寫重要度、來源、日期、命中關鍵字、摘要、「對優樂地的意義」、原文連結；最後有「說明」段。
- 主管回饋單：勾選後週報附上逐則「要／不要」與摘要長度、每期則數等問題，照簡報第 4 頁做。
- 知識庫：加入 10/15 簡報的 8 則新聞（N19～N26），每則重新打開原文確認；抓不到原文的數字不用（例如 LEAP 2.0 的 56 國、1,000 家）。

**測試結果**：10 項測試重跑都通過，網站模式也測過。兩項因設計調整而改變：貼上新聞改判為「法規與準則・碳盤查與碳費・重要度 高」；週報預設勾選改成「重要度高＋近兩週」。

**要副執行長決定的事**：目前關鍵字清單沒有「綠電、RE100、IFRS」，所以台積電綠電、IFRS 接軌藍圖等情報相關度是 0 分。要不要把這些詞加進關鍵字清單（管理層系統那邊也要一起改）？
