# 移交手冊：項目進度看板

## 這是什麼
每週讀一次公司現有的「項目進度看板」Excel，做成一頁摘要，告訴主管：
- 哪些案子**已過下一步日期**、**快到期**、**卡關**、**很久沒有變化**；
- 跟上週相比，哪些問題是**新出現**、哪些**已解除**；
- 看板本身**哪裡缺資料**（例如進行中卻沒填下一步日期）。

系統**只讀不改**看板，**不讀「卡點／風險」「備註」兩欄**（含客戶未公開資訊），**「近期下一步」也不會出現在報表上**（只用來判斷案子有沒有更新）。不會自動通知任何人。

## 每週怎麼跑
1. 專案組會議後，看板更新完，把最新一份存到 `data/raw/`，檔名以「項目進度看板」開頭，例如 `項目進度看板_20261012.xlsx`。
2. 在專案資料夾打開終端機，輸入：
   ```
   .venv/bin/python scripts/run_progress.py
   ```
3. 打開 `data/out/progress/` 裡最新的檔案。

想先看看長什麼樣子：`.venv/bin/python scripts/run_progress.py --sample`（假資料，輸出在 `data/out/progress_sample/`）。

**注意**
- 同一天用同一份看板跑兩次沒關係，結果一樣。同一天換另一份看板再跑，會取代前一次的紀錄，報表會註明。
- 不能往前補跑：跑過 10/14 之後就不能再跑 10/7，系統會顯示「未執行：…」並停止，不會動到任何檔案。
- 系統會自動取 `data/raw/` 裡檔名排最後的看板。檔名請一律用「項目進度看板_年月日」，排序才會正確。

## 看板要長什麼樣子
就是現在用的那份，不用改格式。系統需要：
- 「項目看板」分頁；
- 標題列有「客戶／案子、類別、階段、負責人、近期下一步、下一個日期」；
- 階段用下拉選單裡的值（規劃中、洽談中、進行中、卡關、結案中、已完成、暫緩）；
- 標題列上方保留「來源：2026/10/5 會議紀錄」這類文字，系統用它判斷看板是不是最新的。

分頁或欄名改了，請改 `config/progress_columns.yaml` 對應，不用改程式。

## 輸出怎麼看
| 檔案 | 內容 |
|---|---|
| `進度看板_日期.xlsx` | 總覽（三句結論、紅黃綠數量）、預警清單、項目明細（燈號上色）、本週變化、負責人案數、資料品質 |
| `進度摘要_日期.md` | 一頁摘要，可直接貼到郵件或會議紀錄 |
| `summary.json` | 給之後的「管理層週報」讀，不用打開 |

**燈號**
| 燈號 | 規則 | 意思 |
|---|---|---|
| 紅 | P01 下一步日期已過 | 下一個日期已過，階段還不是「已完成」 |
| 紅 | P03 卡關 | 階段是「卡關」 |
| 黃 | P02 下一步即將到期 | 7 天內（含今天）到期 |
| 黃 | P04 長期沒有變化 | 連續 14 天，階段、下一步、日期都沒變 |
| 黃 | P05 負責案數偏多 | 同一人負責超過 5 個進行中的案子。**排程參考，不是績效評估** |
| 綠 | — | 沒有預警 |

天數門檻都在 `config/thresholds.yaml`，目前是起始值，待主管確認。

## 常見狀況
| 看到什麼 | 代表什麼 | 怎麼處理 |
|---|---|---|
| 「注意：看板資料日期是…距今 9 天」 | 看板可能沒更新，有些「已過日期」其實已經做完 | 請負責人更新看板後重跑 |
| 「進行中卻沒有下一步日期」 | 系統無法判斷是否延誤 | 請負責人補上「下一個日期」 |
| 「案名重複」 | 兩列用了一樣的案名，無法和上週比較 | 把案名改成不同 |
| 「看板上消失的案子」 | 上週有、這週沒有 | 確認是刪除還是改名；改名的話會變成一案消失、一案新增 |
| 「快照不足 14 天，長期沒有變化可能漏報」 | 剛開始用，紀錄還不夠兩週 | 正常，跑滿兩週後就會消失 |
| 「未執行：找不到…看板檔案」 | `data/raw/` 裡沒有看板 | 把看板放進去，檔名以「項目進度看板」開頭 |
| 「未執行：看板…無法正確讀取（缺少欄位…／找不到分頁…）」 | 看板的分頁或欄名被改了，系統停下來，避免產生「沒有需要注意」的錯誤報表 | 把欄名改回來，或改 `config/progress_columns.yaml` |
| 「未執行：看板必須是 .xlsx 檔」 | 存成了 .xls 或 .csv | 用 Excel「另存新檔」選 .xlsx |
| 「data/raw 裡有不是 .xlsx 的看板檔…已略過」 | 最新的看板可能存錯格式，系統讀的是舊的 .xlsx | 把最新的看板另存為 .xlsx |
| 「未執行：config/thresholds.yaml 的 … 應為 … 以上的整數」 | 門檻填成文字或負數 | 改成數字，例如 7 |
