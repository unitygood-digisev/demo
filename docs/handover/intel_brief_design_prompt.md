# Claude Design 提示詞：永續情資日報／週報版面

> 用法：把下面「提示詞」整段貼進 Claude Design。要套用真實內容時，再把當天的日報 Word 檔或文字一起貼上。
> 真實內容含客戶名稱與內部研判，屬「內部一般」，依 CLAUDE.md 第 4 節只能用公司統一帳號操作。
> 內容結構以副執行長 2026-10-15 修訂版為準（她確認內容全部攸關、分析正確，只要求改善版面與呈現方式）。

---

## 提示詞

請幫我設計一份「永續情資日報」的版面，另外做一個「週報」版本。我要的是可以重複使用的版型，每天替換內容就能產出。

### 1. 這份報告是什麼、給誰看
- 公司：優樂地永續（台灣的永續設計與 ESG 顧問公司）。
- 讀者：執行長、副執行長和各部門主管。大多在手機上看郵件，也會在電腦上看或印成 A4。
- 目的：主管花 3 分鐘看懂今天跟公司生意有關的永續新聞，決定要不要點開原文、要不要分派給業務。
- 語言：繁體中文，夾雜英文專有名詞（IFRS S2、TNFD、LEAP 2.0、ETS 等）。

### 2. 版面結構（順序固定，內容和用字不可更動）
1. **刊頭**
   - 報告名稱「永續情資日報」、日期與星期、副標「優樂地永續服務｜依關鍵字清單主題彙整｜每主題當日前三大新聞」。
   - 資料等級標籤「資料等級：內部一般｜僅供公司內部主管閱讀」，要醒目但不搶眼。
2. **今日一句話**：一段約 150 字的總結，是全篇最重要的文字。
3. **一、今日要點**（3–5 張卡片）
   - 每張卡片包含：編號、分類標籤（例如［法規］［案源］［人權］［自然］）、標題、2–3 句說明、「→ 詳見 A1-1、A1-2」的互相參照。
   - 點互相參照的代碼要能跳到對應的新聞。
4. **二、商機與行動雷達**
   - 表格四欄：情資事件、對應服務、建議動作、時點。
   - 表格上方有一行說明「研究團隊研判，建議動作需由業務負責人確認」。這行一定要看得到。
5. **三、近期重要日程**
   - 表格三欄：日期、事項、相關情資代碼。
   - 適合做成時間軸。
6. **四、主題索引**
   - 16 個主題，分四大類：壹、法規與準則（A）；貳、政策與市場（B）；參、產業與議題（C）；肆、客戶與同業動態（D、E）。
   - 每列四欄：代碼、主題、則數、主題觀點（一句話的 So what）。
   - 則數寫「從缺」的主題要淡化，但不要隱藏。
   - 可以做成一張一眼看完的總覽，例如格狀卡片或熱度圖。
7. **五、主題情資**（主體，每天約 30–40 則）
   - 依四大類 → 主題 → 新聞三層排列。
   - **主題標頭**：代碼（A1）、主題名稱、關鍵字（小字）、「主題觀點」一句話。
   - **每則新聞**：
     - 代碼（A1-1）
     - 重要程度 1–5
     - 新聞標題，點了開原文
     - 來源｜發布日期｜命中的關鍵字
     - 「摘要」：只寫原文事實
     - 「對優樂地的意涵」：研究團隊研判，要和摘要明顯區分，讓人一眼看出這是我們的看法、不是新聞內容
     - 「補充」：選填，例如另一家媒體的說法、或口徑差異
   - 從缺的主題保留標頭，寫「本期從缺」。
8. **六、說明**：蒐集範圍、分類方式、重要程度定義、免責說明。用小字，放最後。
9. **回饋單**（選用，放在最後一頁）
   - 各主題「實用／可刪」勾選表，加上幾個版面問題。
   - 印出或用 Word 開時要能勾選、填寫。

### 3. 視覺需求
- **掃讀優先**：主管多半只看「今日一句話＋今日要點＋重要程度 5 的新聞」，這三樣要最先被看到。其他內容可以收合，或用較低的視覺層級。
- **重要程度**用一致的顏色或圖示：5 直接影響案源或營收、4 核心服務相關、3 需掌握的趨勢、2 背景資訊。色盲也要能分辨，所以要同時用數字或圖示。
- **四大類**各用一個辨識色，只用在代碼與小標，不要大面積上色。
- **品牌色**：深綠（建議 #0F4C45）為主、草綠（#2E8B6E）為輔。整體要專業、乾淨，像顧問公司的研究簡報，不要像新聞網站。
- **字體**：Noto Sans TC 或微軟正黑體。內文在手機上至少 15px，印成 A4 時至少 9.5pt。
- **「摘要」與「對優樂地的意涵」**：用不同的底色或左邊框區分。「意涵」旁邊標「研判」。
- **互相參照**：A1-1 這類代碼在網頁版要能點，點了跳到該則新聞。
- **連結**：每則新聞的標題可以點開原文；印成紙本時，原文網址要以小字印出。

### 4. 要交付的東西
1. **日報網頁版**：響應式，手機和電腦都好讀。要能直接貼進郵件，所以用內嵌樣式、不依賴外部字型或程式也能正常顯示。
2. **日報 A4 列印版**：同一份內容，排成適合列印與存 PDF 的版面，每頁有頁碼與資料等級頁尾。
3. **週報版本**，和日報的差別：
   - 刊頭改「永續情資週報」，日期改區間，例如「2026-10-12 ～ 10-18」。
   - 「今日一句話」改「本週一句話」，「今日要點」改「本週五大要點」。
   - 新增「本週主題熱度」：16 個主題各自的則數與上週比較。
   - 每主題列前五則，其餘只列標題。
   - 「商機與行動雷達」和「近期重要日程」保留，日程延伸到未來四週。
4. **一頁設計說明**：色彩、字級、間距、元件，例如新聞卡、要點卡、表格、標籤。之後要讓程式自動套用這套樣式。

### 5. 不能做的事
- 不改寫、不刪減、不新增任何新聞內容或數字。示範內容可以用下面的假資料。
- 「對優樂地的意涵」和「商機與行動雷達」是研判，版面上不能讓它看起來像事實或原文。
- 不要加入圖庫照片或裝飾性插圖。圖示只用在重要程度、分類標籤、日程這類功能性元素。
- 資料等級標籤和「僅供公司內部主管閱讀」不能省略。

## 給負責人：之後怎麼接回系統
1. 在 Claude Design 做好版型後，請把「設計說明」和網頁版的 HTML 存起來，放到 `docs/design/`。
2. 系統目前已經會依主題分組，每個主題列前三則。副執行長版的「摘要」「對優樂地的意涵」「今日要點」「商機與行動雷達」需要大模型產生，要等決定使用的模型後才能自動化。依 CLAUDE.md 第 4 節，必須經過 `src/shared/llm_client.py`。
3. 在那之前，可以用副執行長版的內容，加上本文件的版型，手動產出。
