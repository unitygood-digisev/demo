# 移交手冊：外部情報摘要

## 這是什麼
每天自動整理主管機關、國際準則、同業、客戶的新聞，挑出和公司有關的，做成一頁摘要。主管不用自己逐一看網站。

- 只看**公開**網站，不碰任何公司內部資料。
- 不會登入網站、不會繞過付費牆、網站不允許的就不抓。
- 不會自動寄給任何人，只產生檔案。

## 需要準備的兩份清單（由主管決定）
| 檔案 | 內容 | 怎麼改 |
|---|---|---|
| `config/sources.yaml` | 要看哪些網站（需要有 RSS 新聞訂閱網址） | 用記事本打開，照檔案裡的範例新增一段 |
| `config/keywords.yaml` | 哪些詞代表「和公司有關」，以及重要程度 1–5 | 同上 |

改完存檔即可，不需要改程式。格式錯誤時，下次執行的摘要會在「來源異常」列出是哪一筆有問題。

## 每天／每週怎麼跑
在專案資料夾打開終端機，輸入：

| 什麼時候 | 輸入這一行 |
|---|---|
| 每天（建議上班後） | `.venv/bin/python scripts/run_intel.py` |
| 每週五 | `.venv/bin/python scripts/run_intel.py --weekly` |
| 想先看看長什麼樣子（用假資料） | `.venv/bin/python scripts/run_intel.py --sample --as-of 2026-10-14 --weekly` |

同一天跑兩次沒關係，結果會一樣，不會重複。

## 會產生哪些檔案（在 `data/out/intel/`）
| 檔案 | 給誰看 | 內容 |
|---|---|---|
| `每日摘要_日期.md` | 主管 | 第一句是結論；接著是來源異常、四組情報（法規與準則／同業動態／客戶動態／其他）、低相關附錄 |
| `每週彙整_日期.docx` | 主管 | 過去 7 天的相關情報，每則有標題、來源、日期、兩句摘要、對優樂地的意義、原文連結 |
| `情報追蹤表.xlsx` | 主管 | 所有看過的文章。看過的請把「已讀」欄改成「已讀」，下次重新產生時會保留 |
| `summary.json` | 系統 | 給之後的「管理層週報」讀，不用打開 |

## 怎麼看摘要
- **相關度幾分**：命中的關鍵字重要程度加起來。後面括號會寫命中了哪些詞，方便判斷為什麼被選中。
- **其他來源連結**：同一件事有好幾家報導時，合併成一則，其他報導的連結列在這裡。
- **附錄：低相關**：沒有命中關鍵字的文章，不放進摘要但保留，避免漏看。
- **⚠ 開頭的提醒**：摘要可能超過字數或格式有問題，請直接看原文。
- **「模擬摘要」**：表示正式的摘要模型還沒設定，摘要只是原文第一句，不是正式內容。

## 常見狀況
| 看到什麼 | 代表什麼 | 怎麼處理 |
|---|---|---|
| 「來源清單是空的」 | `sources.yaml` 還沒填 | 請主管提供來源清單 |
| 「關鍵字清單是空的」 | `keywords.yaml` 還沒填 | 請主管提供關鍵字 |
| 某來源「robots.txt 不允許抓取」 | 該網站不讓程式讀取 | 從清單移除，或改由人工追蹤 |
| 某來源「連線逾時」「網址無法連線」 | 網站暫時連不上或網址錯了 | 隔天再跑；連續幾天都這樣就檢查網址 |
| 某來源「第一版只支援 RSS」 | 這個來源是一般網頁 | 找該網站的 RSS 網址；沒有的話告訴負責人 |
| 「本期無符合項目」 | 今天沒有命中關鍵字的新文章 | 正常；若連續很多天都這樣，可能關鍵字太少 |
| 摘要寫「僅標題，內容待確認」 | 該網站只提供標題 | 點原文連結看 |

## 調整準確度（試跑一兩週後做一次）
1. 執行 `.venv/bin/python scripts/intel_eval.py make-sheet`，會產生 `data/out/intel/標記表.xlsx`（最多 30 篇）。
2. 請主管在最後一欄填「相關」或「不相關」。
3. 執行 `.venv/bin/python scripts/intel_eval.py score data/out/intel/標記表.xlsx`，結果寫在 `docs/intel_eval.md`。
4. 依結果調整 `config/thresholds.yaml` 的 `relevance_min_score`（相關門檻）。

## 目前的設定值（都待主管確認）
| 設定 | 目前值 | 意思 |
|---|---|---|
| 相關門檻 | 1 分 | 命中任何一個關鍵字就算相關 |
| 標題相似度 | 0.85 | 標題相似到這個程度就當成同一件事 |
| 每期最多則數 | 不設上限 | 全部列出 |
