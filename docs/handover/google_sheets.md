# 設定說明：把週報同步到公司 Google 試算表

給：公司 Google Workspace 管理員或主管（只需設定一次，約 20 分鐘）
目的：讓 `run_weekly.py` 每週跑完後，自動把結果寫進一份只有執行長與主管看得到的 Google 試算表。

> Google 的畫面與選單名稱偶爾會改，若找不到下面寫的按鈕，請用畫面上的搜尋列搜尋關鍵字。

## 一、建立服務帳號（給程式用的帳號）
1. 用**公司帳號**登入 Google Cloud Console（console.cloud.google.com）。
2. 建立一個新專案，例如「管理層系統」。
3. 在「API 和服務」中，啟用 **Google Sheets API** 與 **Google Drive API**。
4. 在「IAM 與管理 → 服務帳號」建立服務帳號，名稱例如 `mgmt-suite-writer`。不需要給它任何專案角色。
5. 進入這個服務帳號 →「金鑰」→「新增金鑰」→ 選 **JSON**，下載一個 `.json` 檔。
   - **這個檔案等同密碼**：不要寄出、不要放進專案資料夾、不要上傳到雲端硬碟。
   - 建議放在執行系統那台電腦的使用者資料夾，例如 `C:\Users\…\mgmt-secrets\` 或 `~/mgmt-secrets/`。
6. 記下服務帳號的電子郵件（長得像 `mgmt-suite-writer@專案名稱.iam.gserviceaccount.com`）。

## 二、建立試算表並分享
1. 在公司的 Google 雲端硬碟（建議放在第 1 題決定的共用資料夾）建立一份空白試算表，命名「管理層系統」。
2. 按「共用」：
   - 加入第 6 步的**服務帳號電子郵件**，權限選「**編輯者**」，取消「通知對方」。
   - 加入執行長與主管，權限選「檢視者」（或依主管決定）。
   - **不要**開啟「知道連結的任何人」。
3. 從試算表網址複製 ID：`https://docs.google.com/spreadsheets/d/這一段就是ID/edit`。

## 三、在執行系統的電腦上設定
在專案資料夾的 `.env` 檔（從 `.env.example` 複製而來，不會上傳）加入兩行：
```
MGMT_SHEET_ID=剛剛複製的試算表 ID
GOOGLE_APPLICATION_CREDENTIALS=金鑰檔的完整路徑
```
- 系統每次同步都會自動讀 `.env`，不需要另外設定。
- 路徑可以用 `~` 代表個人資料夾（例如 `~/mgmt-secrets/key.json`），有空白時可以用引號括起來。
- 可以在行尾加說明，例如 `MGMT_SHEET_ID=abc123  # 管理層系統`（「#」前面要空一格）；如果值本身含「 #」，請用引號括起來。
- 存檔時請選 UTF-8 編碼（記事本「另存新檔」最下方的「編碼」）。

## 四、試一次
1. 先不連 Google 看看會寫什麼：
   ```
   .venv/bin/python scripts/sync_sheets.py --preview
   ```
   每個分頁會存成一個 CSV，放在 `data/out/sheets_preview/`。
2. 正式同步：
   ```
   .venv/bin/python scripts/sync_sheets.py
   ```
   成功會顯示「已同步到 Google 試算表：週報、進度預警、…」。打開試算表確認。
3. 之後每週只要跑 `.venv/bin/python scripts/run_weekly.py`，最後一步就會自動同步。

## 試算表裡有什麼
| 分頁 | 內容 | 更新方式 |
|---|---|---|
| 週報 | 本週結論、關鍵指標、需要決定的事項、外部情報、資料品質 | 每週覆蓋 |
| 進度預警 | 預警清單（燈號、規則、案子、為什麼、建議跟誰確認） | 每週覆蓋 |
| 進度明細 | 每案的類別、階段、負責人、下一個日期、燈號 | 每週覆蓋 |
| 外部情報 | 情報追蹤表 | 每週覆蓋 |
| 說明 | 資料截至、執行編號、資料等級、待補清單、計算方法 | 每週覆蓋 |
| 指標歷史 | 每週一列的關鍵指標，可自己畫趨勢圖 | 只新增；同一週重跑只更新那一列 |

- 系統**只寫入、不讀回**（指標歷史除外）。在系統分頁裡手動修改的內容，下次同步會被覆蓋。
- 想做自己的圖表或筆記，請**另外新增分頁**，系統不會動它。如果有和系統同名、但不是系統寫的分頁，系統會停下來提醒，不會覆蓋。
- 「指標歷史」每次只改本週那一列的系統欄位；主管自己加的欄、註記列、公式和其他週的資料都不會被動到。數字以數字寫入，可以直接畫趨勢圖；新的一週接在最後一列之後。
- 不會出現：看板的「卡點／風險」「備註」「近期下一步」，以及任何財務資料。

## 常見訊息
| 看到什麼 | 怎麼處理 |
|---|---|
| 「未同步：尚未設定 Google 試算表…略過同步」 | 還沒做第三步；本機報表不受影響 |
| 「找不到服務帳號金鑰檔」 | `.env` 的路徑寫錯，或金鑰檔被移走 |
| 「找不到試算表，或沒有分享給服務帳號」 | 試算表 ID 錯，或忘了把服務帳號加為「編輯者」 |
| 「Google 拒絕連線（代碼 403）」 | 沒有啟用 Sheets API／Drive API，或權限被移除 |
| 「寫入 Google 試算表時失敗…試算表目前部分已更新：已寫入…；未寫入…」 | 多半是網路暫時不通，稍後再跑一次 `sync_sheets.py`；未寫入的分頁仍是上週的內容 |
| 「試算表裡已有一個「X」分頁，但看起來不是系統寫的」 | 把那個分頁改名，或在 `config/sheets.yaml` 改用其他分頁名稱 |
| 「.env 不是 UTF-8 編碼」 | 用記事本開 `.env`，「另存新檔」時編碼選 UTF-8 |
| 「週報資料檔…裡的日期和檔名不符」或「缺少欄位」 | 本機報表檔被改過或複製錯；重新跑一次 `run_weekly.py` |
| 某分頁寫「…本週執行失敗，本頁未更新」 | 那個系統這週沒跑成功；試算表不會拿舊資料充當本週 |

## 要停用時
- 暫停：把 `config/sheets.yaml` 的 `enabled` 改成 `false`。
- 永久停用：在 Google Cloud Console 刪除服務帳號的金鑰，並刪除電腦上的金鑰檔。

## 誰負責
| 工作 | 負責人 |
|---|---|
| 建立服務帳號與試算表、管理分享名單 | 待主管指定（Workspace 管理員或主管） |
| 保管金鑰檔 | 執行系統那台電腦的負責人 |
