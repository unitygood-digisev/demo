# 版本紀錄

## v2.0（溯稿 SourceDraft 系統化）

### 提示詞 v1 → v2

| 項目 | v1 | v2 |
| --- | --- | --- |
| 缺口處理 | 「合規柔性修飾」 | 缺口明示、不以修辭掩蓋，沿用內容須標註來源年度 |
| 範例數據 | 12,450 ÷ 350 誤寫成 32.5 | 修正為 35.6，並加入驗算規則 |
| 輸出版本 | 僅帶標記版 | 新增 internal／client 兩種模式 |
| 計算規則 | 無 | 新增算式、分母口徑、往年自洽驗算、進位規則 |
| 異常數據 | 未規定 | 矛盾、異常波動、單位不明一律標記不擇一 |
| 變數命名 | pastyearfinal_section | past_year_final_section 等，並新增 output_mode |

### 系統化後新增（提示詞以外）

| 項目 | 做法 |
| --- | --- |
| 計算交給程式 | Step 1 由模型抽出數值與算式，加總／平均／占比／同比全部由程式以 ROUND_HALF_UP 計算，Step 2 只能引用結果 |
| 往年自洽驗算 | 往年完稿宣稱的總數、均值自動重算；不一致時（例如 v1 的 32.5）標記「往年不自洽」，同比改用可驗算的數值 |
| 異常與口徑旗標 | 同比超過 ±30% 標記「異常波動」；同比兩端口徑不同標記「口徑不一致」 |
| Step 3 自動檢核 | 重算每個 [依…計算] 錨點、比對正文每個數值的來源、檢查模式標記、附錄狀態限用值、缺口覆蓋、百分比進位 |
| 交付格式 | Markdown＋Word（待補處黃底、錨點灰色小字）＋檢核報告＋事實表；檔名依作業手冊四段式並自動遞增版號 |
| 物料讀取 | 直接讀 docx／xlsx／pdf，保留〔表N〕〔工作表 · 列〕〔第N頁〕錨點，客戶原檔不修改 |
