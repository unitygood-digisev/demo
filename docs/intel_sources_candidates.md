# 每日情報郵件：新聞來源勾選表

給：副執行長
日期：2026-10-15
請在要用的來源前打勾（☑），不要的留空。勾完後，我會把勾選的來源寫進系統。

> 每個來源都在 2026-10-15 實際讀取過一次，並確認網站允許程式讀取、沒有登入。
> 「可以直接用」的來源，都採用政府資料開放授權條款或公開 RSS，公司內部使用沒有疑慮。

## 結論
- **可以馬上用的有 9 個**，全部是主管機關與國際準則機構的官方 RSS：金管會、職安署、觀光署、TNFD、歐盟 CBAM。
- **另外 4 個要多寫一點程式**才能讀：環境部（含氣候變遷署）、IFRS／ISSB、SBTi、GRI。它們沒有 RSS，要讀開放資料或網頁。
- **媒體類（ESG遠見、中央社、今周刊、環境資訊中心等）目前都不能自動讀**：使用條款限「個人／非商業」或禁止擷取，要先取得授權或經法務確認。
- **最大的缺口是「同業與客戶動態」**。您清單裡的客戶、同業名稱，主要出現在媒體報導裡；沒有媒體來源，這兩類幾乎抓不到。

## 四、不能用
| 來源 | 原因 |
|---|---|
| Google 新聞搜尋 RSS | 網站規則禁止程式讀取，feed 也寫明只限個人非商業使用 |
| 天下 CSR、B Lab／B Corp | 網站的防護機制擋下程式讀取，依規定不繞過 |
| 政府電子採購網（每日標案） | 開放資料大約落後 6 週，不能每天追新標案；網站聲明非經同意不得利用內容。建議改成**每月回顧**永續、培訓類標案，或由專人每天上網查 |

## 五、請您決定
1. 勾選第一、二節要用的來源（建議全選）。
2. 第二節的環境部開放資料：同意用公司帳號申請 API 金鑰嗎？
3. 第三節的媒體：要不要申請授權？建議先申請**環境資訊中心**（有公開的商用申請表）。
4. 政府採購標案：改成每月回顧，還是由專人每天查？
