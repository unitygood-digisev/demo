# 提示詞 v1（僅供參考，已由 v2 取代）

> 本檔保存 v1 原文以利比對。v1 有兩個已知問題，請勿再使用：
> 1. 「合規柔性修飾」會鼓勵模型用修辭掩蓋資料缺口；v2 改為缺口一律明示。
> 2. 範例把 12,450 ÷ 350 寫成 32.5（正確為 35.6）。溯稿的往年自洽驗算會抓出這類錯誤，見 `tests/test_pipeline.py::test_v1_wrong_past_average_is_flagged`。

## 處理鏈路

輸入物料 A（往年完稿）＋ 輸入物料 B（當年自收表）
→ Step 1 物料解析與事實清洗（提取往年大綱與敘事骨架、清洗自收表、識別新增／缺失／異常）
→ Step 2 邏輯重構與初稿起草（依敘事邏輯重排、管理方針與實施成效說明、標準化表格與解讀、合規柔性修飾）
→ Step 3 溯源錨定與風險標記（插入 [源自自收表: X]、【待顧問複核】、章末《顧問審校與補件清單》）
→ 交付：帶溯源標記的章節初稿（Word）

## 核心要點

- 角色：資深永續報告書撰寫顧問，精通 GRI、TCFD、SASB 與台灣金管會規範。
- 四大目標：重構敘事邏輯（管理方針 → 實施制度與機制 → 年度績效與數據 → 目標與未來展望）、提取並結構化數據、合規性柔性修飾、全鏈路事實溯源。
- 數據缺失：可定性者以公文語言作機制性描述；強制披露指標插入【待顧問複核：自收表未提供具體數值】。
- 溯源標記：`...較上一年度降低 4.2% [源自自收表: 題號/表格名/附件名稱]`；沿用往年制度標註 `[沿用往年完稿描述，請複核制度是否有變更]`。
- 輸入槽位：`{{pastyearfinal_section}}`、`{{currentyearsurvey_data}}`、`{{special_instructions}}`。

## v1 範例（含錯誤）

往年完稿寫「2024 年總培訓時數達 12,450 小時，平均每人受訓 32.5 小時」——以 350 人計算應為 35.6 小時。
預期效果中的「折算人均 32.37 小時」亦未依進位規則（v2 統一為 32.4）。
