# 需要主管回答的問題

給：執行長、各部門主管
目的：系統的設定值要靠下面六個問題的答案來決定。每題先說明這題在問什麼、為什麼要問，再列出可以選的選項，最後留空格給您填寫。
建議：第 6 題（情報來源與關鍵字）最急，回答之後才能開始做第一個系統。其他題目可以在之後兩、三週內陸續回覆。

填答方式：直接在每題的「回答」欄填寫，或在選項前打勾。不確定的題目可以寫「先用建議值」，之後再調整。

## 第 1 題：資料放在哪裡、誰可以看

### 這題在問什麼
系統每週要讀各位提供的 Excel，產生報表。我們需要約定三件事：
1. **原始資料**放在哪個資料夾，例如項目清單、會計匯出檔。
2. **產生的報表**放在哪個資料夾。
3. 這些資料夾**誰可以開、誰可以改**。

### 為什麼要問
- 財務、工時、合約這些資料屬於「內部敏感」或「客戶機密」。如果放在全公司都能開的資料夾，等於讓所有人都看得到。
- 系統的原則是原始檔只讀不改，所以要有一個固定位置，讓負責同仁每週把最新檔案放進去。
- 程式倉庫裡**不會**放任何真實資料，所以需要另一個公司內部的存放位置。

### 可以選的選項
| 選項 | 適合情況 | 注意事項 |
|---|---|---|
| A. 公司的 Google 雲端硬碟共用資料夾 | 公司本來就用 Google Workspace | 要確認是公司帳號，不是個人帳號；資料夾權限只開給執行長和主管 |
| B. 公司的 OneDrive／SharePoint | 公司本來就用 Microsoft 365 | 同上 |
| C. 公司內部的共用硬碟（NAS） | 有公司內部網路硬碟 | 要確認實習生的電腦連得到 |
| D. 執行長或指定主管電腦上的資料夾 | 暫時沒有共用空間 | 備份和交接比較麻煩，只建議當過渡做法 |

### 建議的資料夾分法（可以調整）
```
管理層系統/
  原始資料/        ← 各位放 Excel 的地方（只有提供資料的人和實習生可以放）
  報表_一般/       ← 進度看板、外部情報摘要（執行長與所有主管可看）
  報表_敏感/       ← 財務、工時報表（只有執行長與指定主管可看）
  報表_客戶機密/   ← 合約、商機報表（只有執行長與指定主管可看）
```

### 需要您回答
| 項目 | 回答 |
|---|---|
| 用哪個選項（A／B／C／D） | |
| 資料夾位置或名稱 | |
| 「報表_敏感」與「報表_客戶機密」誰可以看 | |
| 實習生能否存取原始資料夾 | |

## 第 2 題：財務資料可以提供到什麼範圍

### 這題在問什麼
「項目財務總覽」這個系統要回答三個問題：**項目有沒有賺錢、哪些款項還沒收到、哪些項目花的錢和做的進度對不上**。要回答這些問題，需要從會計系統匯出三份資料。這題請**執行長**決定：可以提供哪幾份、要不要先去掉客戶名稱、從什麼時候開始。

在執行長同意之前，這個系統只會用假資料開發，不會碰任何真實財務資料。

### 「財務資料」具體是指這三份

**① 合約資料**：每個項目簽了多少錢
| 欄位 | 用途 |
|---|---|
| 項目編號 | 用來和進度看板的項目對起來 |
| 客戶 | 顯示用；可以改成代號 |
| 合約總價 | 計算「已請款比例」「成本佔合約比」 |
| 幣別 | 不是新台幣的會標「幣別待確認」，系統不會自己換算 |
| 付款期數與比例 | 例如分 3 期：30%／40%／30% |

**② 專案結算資料**：每個項目到目前為止的收入和成本（會計系統的「專案結算」報表）
| 欄位 | 用途 |
|---|---|
| 項目編號 | 對應項目 |
| 已認列收入 | 計算毛利率 |
| 已發生成本 | 計算毛利率、成本佔合約比 |
| 外包成本 | 看外包佔多少 |

**③ 應收帳款資料**：開了哪些發票、收到錢沒有
| 欄位 | 用途 |
|---|---|
| 發票號碼 | 每張發票一筆 |
| 項目編號 | 對應項目 |
| 發票日、到期日 | 計算「逾期幾天」 |
| 金額、已收金額 | 計算「還有多少沒收」 |
| 收款日 | 未收就空白 |

### 系統會算出什麼
| 結果 | 算法 |
|---|---|
| 毛利率 | （已認列收入 − 已發生成本）÷ 已認列收入 |
| 未收金額 | 發票金額 − 已收金額 |
| 帳齡 | 今天距離到期日幾天，分成未到期、0–30、31–60、61–90、超過 90 天 |
| 已請款比例 | 已開發票總額 ÷ 合約總價 |
| 成本佔合約比 | 已發生成本 ÷ 合約總價 |

如果系統算出來的數字和會計系統不一樣，**一律以會計系統為準**，報表會列出差異。

### 系統**不需要**的資料
薪資、個人報帳、銀行帳號、稅務資料、公司整體損益表。如果匯出檔裡有這些欄位，系統讀入後會直接丟掉。

### 可以選的範圍
| 選項 | 內容 | 可以回答的問題 |
|---|---|---|
| A. 三份都提供 | 合約＋結算＋應收 | 全部 |
| B. 只提供應收帳款 | 只有③ | 哪些錢還沒收、逾期多久 |
| C. 應收＋結算 | ②＋③ | 收款狀況＋毛利率，但沒有「已請款比例」 |
| D. 先提供去識別樣本 | 三份各前 10 列，客戶名稱改代號 | 只用來確認格式，不產生真實報表 |
| E. 暫不提供 | — | 這個系統延後 |

建議先選 **D**，確認格式沒問題之後，再決定要選 A、B 還是 C。

### 需要您回答
| 項目 | 回答 |
|---|---|
| 同意的範圍（A／B／C／D／E） | |
| 客戶名稱要不要改成代號 | |
| 會計系統是哪一套？由誰匯出？ | |
| 會計的項目編號和進度追蹤用的項目編號一樣嗎？ | |
| 多久更新一次（每週／每月） | |
| 執行長核准日期 | |

## 第 3 題：預警門檻要設多少

### 這題在問什麼
「預警門檻」就是**「到什麼程度系統要提醒您」的那條線**。例如「里程碑 7 天內到期但還沒開始，就標黃色」，這個「7 天」就是門檻。

- 門檻設得太緊，每週會跳出一大堆提醒，大家就不看了。
- 門檻設得太鬆，真正有問題的項目反而沒被提醒。

下面是目前的建議起始值。規格裡沒有給起始值的寫「待補」，需要您決定。這些數字都可以隨時改，改設定檔就好，不用改程式。

### 項目進度看板（第一批做，最需要先確認）
| 規則 | 意思 | 燈號 | 建議起始值 | 您的決定 |
|---|---|---|---|---|
| 里程碑逾期 | 預計完成日已過，但狀態不是「已完成」 | 紅 | （沒有門檻，過期就算） | — |
| 里程碑即將到期 | 幾天內到期，但還「未開始」 | 黃 | 7 天 | |
| 長期沒更新 | 進行中的項目超過幾天沒有任何更新紀錄 | 黃 | 14 天 | |
| 負責人負荷偏高 | 同一人同時負責幾個進行中項目以上 | 黃 | 超過 5 個 | |
| 結案逾期 | 預計結案日已過，但狀態不是「已結案」 | 紅 | （沒有門檻，過期就算） | — |

「負荷偏高」只會列出「誰、負責幾個項目」，按姓名排序，**不做排名、不評價個人表現**。

### 項目財務總覽
| 規則 | 意思 | 燈號 | 建議起始值 | 您的決定 |
|---|---|---|---|---|
| 長期未收款 | 發票逾期超過幾天還沒收到錢 | 紅 | 90 天 | |
| 毛利率偏低 | 毛利率低於多少 | 黃 | **待補** | |
| 成本進度不符 | 成本已花超過合約的 X%，但里程碑完成率低於 Y% | 紅 | X、Y **待補** | X＝　　Y＝ |

### 外部情報摘要
| 設定 | 意思 | 建議起始值 | 您的決定 |
|---|---|---|---|
| 每期最多幾則 | 一份摘要最多放幾則新聞，太多就看不完 | **待補**（建議 10 則左右） | |
| 相關度門檻 | 分數多少以上才算相關、放進摘要 | 試跑後，用您標記的 30 篇文章來調整 | — |

### 之後的系統（可以晚點再決定）
| 系統 | 設定 | 建議起始值 | 您的決定 |
|---|---|---|---|
| 商機看板 | 同一階段停留超過幾天算「卡關」 | 21 天 | |
| 合約總覽 | 到期前幾天標黃 | 90 天 | |
| 合約總覽 | 到期前幾天標紅 | 30 天 | |
| 工時看板 | 工時填報率低於多少要提醒 | **待補** | |
| 工時看板 | 團隊利用率高於多少標黃 | **待補** | |
| 工時看板 | 群組少於幾人就不顯示（保護隱私） | 3 人 | |
| 週報 | 某個系統超過幾天沒更新，就在週報寫「本週未更新」 | **待補**（建議 7 天） | |

## 第 4 題：週報要看哪幾個指標

### 這題在問什麼
「指標」就是**週報最上面那張表裡的數字**，每週和上週並排比較。一頁週報放得下 5–8 個，請從下面的清單挑出您最在意的。

挑選原則：**能讓您做決定的數字**才放進來。只是「知道就好」的數字可以放在各系統的詳細報表裡。

### 可以選的指標
**項目進度**（最先上線）
| 指標 | 意思 | 起始版已選 |
|---|---|---|
| 紅色預警項目數 | 已逾期的里程碑或項目數 | ✓ |
| 黃色預警項目數 | 快到期或太久沒更新的項目數 | ✓ |
| 進行中項目數 | 目前同時在做的項目總數 | ✓ |
| 本週新增預警數 | 比上週多出來的問題 | |
| 本週解除預警數 | 上週有問題、這週已解決的 | |
| 負荷偏高的負責人數 | 同時負責項目超過門檻的人數 | |

**項目財務**（執行長核准後才有）
| 指標 | 意思 | 起始版已選 |
|---|---|---|
| 未收款總額 | 所有已開發票但還沒收到的錢 | ✓ |
| 逾期超過 90 天未收款 | 最可能收不回來的部分 | ✓ |
| 平均毛利率 | 所有進行中項目的毛利率 | |
| 毛利率偏低項目數 | 低於門檻的項目數 | |
| 成本進度不符項目數 | 錢花了很多、進度卻落後的項目數 | |

**外部情報**
| 指標 | 意思 | 起始版已選 |
|---|---|---|
| 本期相關情報則數 | 本週和公司有關的新聞數 | ✓ |
| 法規與準則類則數 | 其中屬於法規、準則變動的數量 | |

**之後的系統**（現在可以先勾，系統上線後才會出現）
| 指標 | 來自哪個系統 |
|---|---|
| 團隊利用率 | 工時看板 |
| 未來 4 週人力缺口（小時） | 工時看板 |
| 本月新增名單數、報價中金額 | 商機看板 |
| 卡關商機數 | 商機看板 |
| 90 天內到期合約數 | 合約總覽 |
| 前 5 大客戶收入占比 | 合約總覽 |

### 需要您回答
| 項目 | 回答 |
|---|---|
| 勾選 5–8 個指標（寫在上面表格或列在這裡） | |
| 排列順序（最重要的放最前面） | |
| 有沒有清單上沒有、但您每週都想知道的數字？ | |

最後一格很重要。前任實習生的經驗是，主管真正在意的常常只是一個很簡單的數字，例如「這個月還有多少錢沒收」。

## 第 5 題：報表要怎麼送到您手上

### 這題在問什麼
系統做好報表之後，用什麼方式、什麼時間送到您面前。系統**不會自動寄出任何東西**，第一版是產生檔案和一段可以直接貼上的文字，由負責同仁轉發。

### 可以選的方式
| 方式 | 您會收到什麼 | 適合的報表 | 注意事項 |
|---|---|---|---|
| A. 郵件 | 一段週報文字（可直接貼在郵件內文）＋ Excel 或 Word 附件 | 全部 | 敏感報表建議只放共用資料夾連結，不附檔 |
| B. Line | 一段短文字（三句結論＋紅色預警） | 外部情報、進度摘要 | **財務、工時、合約、商機不建議用 Line 傳**，只傳「請到資料夾看」的提醒 |
| C. Google Sheet | 一張持續更新的表格 | 進度追蹤、情報追蹤表 | 第一版先產生 Excel 讓您上傳；自動同步需要另外申請權限，之後再做 |
| D. 共用資料夾 | 每週固定位置多一份新報表 | 全部 | 搭配 A 或 B 提醒「已更新」 |

### 需要您回答
| 項目 | 回答 |
|---|---|
| 週報用哪種方式（可複選） | |
| 外部情報摘要要每天還是每週 | |
| 每週幾、幾點前要收到 | |
| 檔案格式偏好（Excel／Word／只要文字） | |
| 收件人名單（誰收哪幾份） | |
| 誰負責每週轉發 | |

## 第 6 題：外部情報要看哪些來源、追哪些關鍵字

### 這題在問什麼
「外部情報摘要」會每天或每週自動整理新聞，讓您不用自己追。它需要兩份清單：
1. **來源清單**：要去看哪些網站。
2. **關鍵字清單**：哪些詞出現時，代表這則新聞和公司有關。

系統規定不能自己決定來源，因為**看什麼、不看什麼是業務判斷**。下面列的是常見的候選，請勾選、刪除或補充。網址、是否提供 RSS 新聞訂閱，會在您確認後由實習生逐一查證。系統只抓網站允許的內容，不會登入、也不會繞過付費牆。
