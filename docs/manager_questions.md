# 需要主管回答的問題

這些答案決定設定檔的值，請在開始階段 1 前詢問。

1. 資料的存放位置和權限：公司指定的雲端空間或資料夾是哪一個？
2. 執行長是否核准財務資料的使用範圍（決定階段 3 能否開始）？
3. 預警門檻的起始值是否合理：里程碑即將到期天數、無更新天數、負荷上限、毛利率門檻、卡關天數？
4. 管理層週報想看的 5–8 個指標是哪些？
5. 管理層習慣用什麼方式收報表（郵件、Line、Google Sheet）？
6. 外部情報的來源清單和關鍵字由誰提供？
7. 公司有沒有可用的本地模型或適合的電腦（決定內部敏感資料能不能用大模型）？
8. 誰是內部窗口，實習結束後由誰維護？
