# 規格：客戶與合約總覽（系統 8，src/contracts）

目標：管理層看懂哪些合約即將到期、哪些客戶可續約或擴案、客戶收入是否過度集中。
資料等級：客戶機密。不使用大模型，禁止呼叫 llm_client。

## 輸入
- contracts_list.xlsx：contract_id、客戶、專案、金額、幣別、簽約日、起始日、迄止日、是否自動續約（是／否／未確認）、續約條款（原文文字欄）、付款條件（原文文字欄）。聯絡窗口資訊不讀入輸出。
- 第一版只讀結構化清單，不解析合約 PDF。之後若要加 PDF 萃取，必須每筆經人工確認。

## 計算
- 到期天數 = 迄止日 − 今天。
- 分組：已到期、30 天內、31–60 天、61–90 天、超過 90 天。
- 客戶收入集中度：前 5 大客戶合約金額占總金額的比例。
- 續約條款和付款條件：原文複製到輸出，一律標【待法務確認】，禁止摘要、改寫或判斷。

## 預警規則（起始值待主管確認）
- C01 到期天數 ≤ 90 → 黃；≤ 30 → 紅。
- C02 已過迄止日但狀態不是已結案或已續約 → 紅。
- C03 缺迄止日或金額 → 資料品質。

## 輸出
- xlsx：總覽（三句結論、到期分組、集中度）、到期清單（按天數排序）、客戶總覽、資料品質。
- 檔案頁首標「客戶機密：僅執行長與主管」。

## 驗收條件
- 到期天數的邊界（30、60、90 天整）都有測試。
- 續約條款和付款條件的輸出文字與輸入完全一致，且每筆都帶「待法務確認」標籤（測試）。
- 輸出不含任何聯絡人資訊（掃描測試）。

## 不做
- 不解讀合約法律意思，不判斷是否該續約，不發送任何內容。
