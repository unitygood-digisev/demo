## 2. 各模組的做法與假設
- **classify**：四級依序為 公開 < 內部一般 < 內部敏感 < 客戶機密。不認得的等級一律當「客戶機密」。
- **llm_client**：
  - 呼叫時必須給：資料等級、用途（例如 `intel_summary`）、提示詞版本。
  - `config/llm.yaml` 規定兩件事：每個用途最高可用的資料等級（例如 `intel_summary` 只到「公開」），以及每個等級可用哪些後端（雲端／公司帳號雲端／本地／mock）。
  - 等級超過用途上限，或後端不被允許，就丟出例外並記日誌，不會默默降級。
  - 階段 0 只有 mock 後端，不連任何真實模型，也不 import 任何大模型 SDK。另外寫一個測試，掃描 `src/` 確認沒人直接 import SDK。
  - 溫度固定 0。快取放 `data/interim/llm_cache/`，用「模型＋提示詞版本＋輸入」的雜湊當鍵。
  - 日誌只記時間、等級、用途、提示詞版本、輸入雜湊，不記全文。
- **io**：
  - 欄位定義包含名稱、型別（文字／整數／金額／日期／選項）、必填、允許值。
  - 欄位名稱不同時，用 config 的對應表改名，不動原檔。
  - 回傳「資料＋錯誤清單」，錯誤清單每筆有：檔名、Excel 列號（標題列算第 1 列）、欄位、問題。所有錯誤一次列完。
  - 重複 ID 也由 io 檢查。
  - 原始檔只用唯讀方式開啟。
- **schema**：八個 pydantic 模型。每個欄位有繁中描述；缺值的欄位允許是空的，輸出時顯示「待補」。
- **report**：
  - xlsx 和 docx 共用一個版型，md 也一起支援。
  - 每份輸出都有頁尾：資料截至日期、輸入檔名、執行編號、資料等級、待補清單，另外可附「計算方法」段。
  - 空值一律寫成「待補」。
  - 執行編號格式為 `系統-YYYYMMDD-輸入雜湊前 8 碼`，同樣的輸入會得到同樣的編號，方便重跑比對。
- **logging**：檔名照規格用 `shared/logging.py`，以 `shared.logging` 引用，不會蓋掉 Python 內建的 logging。每次執行寫一份 `logs/run_<執行編號>.log`。
- **dates**：
  - 時區用 Asia/Taipei，「今天」可以由參數指定。
  - 接受這些日期寫法：`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`、Excel 日期格，以及民國年 `115/10/14`（只限三位數年份）、`民國115年10月14日`。
  - 兩位數年份（例如 `26/10/14`）、民國 0 年、1950–2100 以外的年份，一律算日期錯誤，不猜。
  - 金額格式化為「NT$ 1,234（元）」。

## 3. 假資料內容（全部虛構，檔名和內容都標「假資料」）
- **系統 1**：
  - 約 8 個項目、15 個里程碑、15 筆更新，客戶名稱像「（假資料）青嵐示範股份有限公司」。
  - 刻意放入：一筆缺必填欄位、一筆重複 project_id、一筆日期錯誤（例如 `2026-13-40`）。
  - 另外放入能觸發 A01–A05 各一次的資料，基準日固定為 2026-10-14。
- **系統 7**：
  - 兩個存檔 RSS（一中一英，各 5–6 則），內容包含一組重複網址、一組相似標題、一則只有標題。
  - 一個故意壞掉的 feed 檔，用來測試「來源異常」。
  - 測試用的來源清單放在 `data/sample/feeds/sources_sample.yaml`，不寫進 `config/sources.yaml`。

## 4. 驗收條件（自檢＋獨立驗收都用這份）
1. `ruff check` 無錯誤；`pytest` 全部通過。
2. llm_client 拒絕以下三種呼叫，並有測試：
   - 用途為 `intel_summary` 時，傳入內部一般、內部敏感、客戶機密或不認得的等級。
   - 等級是內部敏感，卻選了雲端後端。
   - 沒有給等級。
3. llm_client 每次呼叫寫一行 jsonl，內容不含輸入全文（測試）；相同輸入第二次走快取（測試）。
4. io 對「缺兩個欄位＋三列型別錯誤＋重複 ID」一次全部列出，不在第一個錯誤就停（測試）。
5. io 讀檔前後，原始檔的雜湊不變（測試）。
6. report 產生的 xlsx、docx、md 都有完整頁尾，空值顯示「待補」（測試）。
7. dates 的民國年轉換、非法日期、時區有測試。
8. 用假資料跑讀取腳本，三種刻意錯誤都會被列出。
9. 倉庫內沒有 .env、真實資料或金鑰；`src/` 沒有 import 大模型 SDK（測試）。
10. 另開子代理做獨立驗收，依 CLAUDE.md 第 11 節第 5 步的格式回報。
