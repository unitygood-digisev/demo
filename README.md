# 優樂地管理層系統

> 給執行長與主管使用的內部工具。把大家已經在用的 Excel 整理成**一頁看懂**的看板和週報，輸出仍然是 Excel、Word 或郵件文字，不需要學新系統。

## 這是什麼
| 系統 | 回答的問題 | 狀態 |
|---|---|---|
| 外部情報摘要 | 主管機關、同業、客戶最近有什麼新動態？ | 未開始 |
| 項目進度看板 | 哪些項目可能逾期？誰同時負責太多案子？ | 未開始 |
| 項目財務總覽 | 哪些項目不賺錢？哪些款項還沒收？ | 等執行長核准 |
| 管理層週報 | 本週全局一頁看懂 | 未開始 |
| 工時、商機、案例庫、合約 | 依訪談結果再決定 | 未開始 |

目前完成的是**基礎骨架**（階段 0）：讀檔檢查、資料分級保護、報表版型。各系統會一個一個加上去。

## 資料要放哪裡
| 資料夾 | 放什麼 | 會不會上傳到程式倉庫 |
|---|---|---|
| `data/raw/` | 您提供的原始 Excel。系統只讀不改。 | 不會 |
| `data/out/` | 系統產生的報表 | 不會 |
| `data/sample/` | 練習用的假資料 | 會（全部是虛構的） |
| `config/` | 門檻、關鍵字、來源清單等設定，可以直接用文字編輯器改 | 會 |

**需要提供哪些資料：** 請看 `docs/data_requests.md`。
**要改預警門檻：** 打開 `config/thresholds.yaml`，改 `value` 後面的數字即可，不用改程式。

## 資料等級
每份資料都有等級：公開、內部一般、內部敏感、客戶機密。
敏感資料（財務、工時、合約、客戶名單）**不會送到任何雲端 AI 服務**。報表頁首會標出等級，例如「內部敏感：僅執行長與主管」。不確定等級的資料一律當作最高等級處理。

## 怎麼跑（第一次需要請負責同仁協助安裝）

**第一次安裝（只要做一次）**
```
uv venv -p 3.11 .venv
uv pip install -p .venv -e ".[dev]"
```

**檢查輸入檔有沒有問題**（用假資料示範）
```
.venv/bin/python scripts/check_inputs.py data/sample/progress
```
跑完後打開 `data/out/check/資料品質檢查.xlsx`：
- 「總覽」第一行是結論，例如「輸入檔共有 5 個資料問題」。
- 「資料品質」分頁列出每個問題在哪個檔案、第幾列、哪一欄。照著改原始 Excel 後再跑一次。

**確認系統本身正常**
```
.venv/bin/pytest
```
最後一行出現「passed」且沒有「failed」就是正常。

## 遇到問題
| 狀況 | 怎麼辦 |
|---|---|
| 報表寫「待補」 | 原始資料那一格是空的或格式不對，請補上 |
| 「找不到檔案」 | 確認檔名和放的資料夾是否正確 |
| 「日期錯誤」 | 日期請寫成 2026-10-14 或 115/10/14 |
| 其他錯誤訊息 | 把訊息截圖給負責人 |
